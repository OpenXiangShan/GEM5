# GEM5 12宽性能上限探索

**主报告：[决策与阶段结果](report.md)**。先看结论、关键收益和下一步选择；详细证据按需要下钻。

本轮统一以**0.3c实测**，新增配置的1c数值均为估算；采样差异和估算方法见主报告开头。

当前完整结果：保持12宽，理想前端＋4load＋容量将INT从26.73提高到30.21（+13.03%）；单独理想前端为+8.50%。带宽/override气泡拆分的完整145点条件收益为+6.76%/+0.70%。
